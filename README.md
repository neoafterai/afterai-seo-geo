# AfterAI SEO/GEO

**面向海外华人经营者、开发者和网站服务商的 SEO/GEO skill。** 你可以用中文讨论业务和修改方案，同时让网站内容保持澳洲英语、其他目标市场语言，或经过确认的英中双语。它把搜索引擎优化（SEO）与生成式 AI 搜索优化（GEO）放进同一套流程：评估、计划、分批实施、复评与月度维护。

[English](README.en.md) · [开始使用](afterai-seo-geo/USAGE.md) · [技能入口](afterai-seo-geo/SKILL.md)

## 为什么适合海外华人网站

**交流语言、网站语言、目标市场和报告语言分别决定。** 华人经营者用中文提需求，不代表网站应增加中文页面，也不代表业务提供中文服务。Skill 会先问清目标客户和真实服务范围，再决定关键词、页面及要修改的语言。

| 场景 | 处理方式 |
|---|---|
| 你用中文管理一家面向澳洲英语顾客的婚礼摄影网站 | 用中文讨论目标、关键词和计划；网站的标题、描述及正文按澳洲英语修改，不自动添加中文页。 |
| 餐厅或商店确实服务英语和中文顾客 | 先确认现有语言版本、目标地区、简体／繁体选择及两种语言下的真实业务信息，再分别规划页面和搜索问题。 |

同一方法也可用于本地服务、电商、企业服务、软件、内容和机构网站；行业建议按实际业务调整，不把上述例子当作所有行业均已实测的证明。

## 安装范围

只需复制 **`afterai-seo-geo/` 整个文件夹** 到你的 AI 工具支持的技能目录，或让支持本地文件的助手读取其中的 SKILL.md 及其引用文件。无需复制 `docs/` 开发记录。

公开仓库只包含经过审查的项目文件；根目录 `output/` 和客户的 `seo-geo/` 是私有工作记录，不应上传。本项目的 `.gitignore` 默认排除它们，但不会自动保护另一个客户网站仓库；发布前仍需检查实际 Git 跟踪和暂存清单，忽略规则不能撤回已跟踪文件。

安装包共 13 个 `.md` 文件，无 Python、Node、独立 JSON/YAML、插件、gstack 或 superpowers 运行依赖。联网、浏览器、文件编辑、Google Search Console（GSC）和 CMS 权限由使用者的宿主提供；没有能力时返回明确人工步骤和缺测项。项目不要求付费 SEO 工具／API；已有 AI 产品及网站环境由使用者提供。

## 示例

> 使用 AfterAI SEO/GEO，评估这个澳洲婚礼摄影网站。我们用中文交流，网站只面向英语顾客。先问我业务目标和重要关键词，再给评分与分阶段计划；暂时不要修改网站。

只需记住“开始优化”“继续”“本月检查”。助手按 **评估 → 计划 → 实施 → 复评维护** 推进，细节按需展开；你不用填写模板或逐个调用其他 skill。“开始优化”从了解情况和评估开始，不等于允许直接改站。精确阶段指令仍可用，见 [使用说明](afterai-seo-geo/USAGE.md)。

每个客户使用自己的文件夹。记录默认保存为客户目录下 `seo-geo/` 的 Markdown，但要先确认该目录不会随网站发布；否则改用已核实的私有位置，无法确认时只在对话中交付。真实截图和数据导出作为私有证据，不进入公开技能包。

## 四步完成一次优化

1. **评估：**访谈最重要的业务结果、客户给出的关键词、目标市场和网站语言；读取线上网页、本地源码或本地预览，核对关键业务事实，分别给出 SEO、GEO 和视觉体验的证据评分、覆盖范围与缺测项。
2. **计划：**扩展候选词并映射到页面；先排业务事实和 SEO 基础问题，再安排 GEO 内容与测试。把事项分成“最重要、其次、可以稍后”，列出可独立验收和上线的批次。知识库仅在内容需求与维护能力支持时提出。
3. **实施：**在确认的范围内按批次检查与修改。SEO 覆盖抓取和索引、URL 与 canonical、标题和描述、正文、内链、移动体验及适用的 Schema／JSON-LD；GEO 关注可核实的回答、实体信息、来源与 AI 搜索观察。每批检查实际页面、功能和视觉效果，按授权上线后核对线上结果。
4. **复评与月检：**按可比口径重新评分，区分“网站准备度变化”和真实搜索展示、询盘或 AI 提及／引用。给出下一批具体任务；无历史数据时建立首次基线，不编造增长。

助手维护计划与证据，你只需回答关键业务问题、确定优先方向并审阅具体改动。不确定的价格、服务范围、承诺或其他业务事实会先请你确认；已经授权且不依赖这些问题的工作可以继续。

## 适用范围

通用流程不限定澳洲或几个行业，按实际业务组合本地服务、电商、企业服务、软件、内容、个人／机构等类型。

首版提供代码网站与 Shopify 操作指南。是否能自动修改取决于实际连接和授权，不意味着已验证所有 CMS。Shopify 的未发布主题不等于共享产品数据沙盒。

## 怎样判断效果

- SEO、GEO 准备度、视觉体验分别评分，附检查覆盖和证据；诊断分不是搜索平台的排名公式。
- 真实关键词表现、询盘及 AI 提及／引用另列，未测不补造。本地源码不能证明线上收录、排名或 AI 推荐。
- GEO 默认 10 个问题×3 个界面，一轮约 30 次查询，允许人工采集。确有中文受众时可选加测豆包、DeepSeek，单独记录，不冒充默认三平台结果。
- 保留原设计；先确认计划，批次验证，上线前审阅。
- 月检可手动触发；定时执行需宿主实际支持和配置。

不保证关键词第一、AI 推荐第一、流量或询盘增长。查看 [验证记录](docs/evaluation-log.md) 区分文件检查、模拟行为测试与未测试的真实平台。
